# 📃 RasPi-Loon
Удобное приложение, для просмотра расписания МВЕУ

*(Приложение создано только для сайта disto.mveu.ru (учащихся в МВЕУ | МВЕК))*

📚 Приложение написано на [Python](https://www.python.org/) используя библиотеки:
- [Flet](https://github.com/flet-dev/flet/)
- [requests](https://pypi.org/project/requests/)
- [beautifulsoup4](https://pypi.org/project/beautifulsoup4/)

## ⚡ Преимущества
- Расписание можно смотреть без интернета.
- Не нужно входить аккаунт каждый раз, чтоыб посмотреть описание

## ℹ️ Как приложение получает расписание
- Сначало потребуеться **почта** и **пароль** от вашего аккаунт *disto.mveu.ru*
- Приложение будет за вас авторизоваться в аккаунт и получать расписание, скачивая его копию.
- Таким образом вам не придеться подключаться к интернету и входить лишний раз в аккаунт.
  
## 🔒 Важное примечание:
- Данные от вашего аккаунта хранятся исключительно на вашем устройстве.
- Приложение делает запрос только на сайт disto.mveu.ru, не передавая данные 3-им лицам
- *Я хотел использовать запрос на timeo.mveu.ru, чтобы не требовать пароль и почту, но он был приостановлен на момент создания (24 октября) и говорят, что он может перестать работать вовсе.*
