# ❔ Зачем нужны твои данные?
- Данные нужны исключитльно для входа и получения `cookie` профиля
- С помощью `cookie` сайт disto.mveu.ru даёт доступ к расписанию
- Казалось бы: нужно сохранять только `cookie`, но вот проблема, после истечении некоторого времени `cookie` перестаёт действовать и сайт снова просит данные для входа.

# 🔒 Хранение данных
- Твои данные храняться только на твоём устройстве.
- Когда ты вводишь данные, при клике `"Сохранить"`
твои данные записываються в файл `[APP]/src/saves/userdata.json`
- В файле `userdata.json` также храниться временный
`cookie` и `lastupdate` - время последнего авто-обновление

# ❓ Почему не timeo.mveu.ru
- Да, и в правду на данном сайте можно посмотреть  расписания бкз входа. Проблема в том, что он не работал на этапе разработки и возможно перестанет работать вовсе
- Если `timeo.mveu.ru` будет работать нормально, то я сделаю возможность просматривать расписания без входа
